# Créditos

O IVO LIVE usa estas partes de terceiros, cada uma com a sua licença:

| Parte | Para que serve | Licença |
|---|---|---|
| [RootEncoder](https://github.com/pedroSG94/RootEncoder), de Pedro Sánchez | Codificar o vídeo e transmitir (RTMP/SRT) | Apache 2.0 |
| [ONNX Runtime](https://github.com/microsoft/onnxruntime), da Microsoft | Rodar as IAs no celular | MIT |
| [DPDFNet](https://huggingface.co/Ceva-IP/DPDFNet), da Ceva | Redução de ruído do microfone | Apache 2.0 |
| MediaPipe Selfie Segmentation, do Google (conversão ONNX: onnx-community) | Recortar a pessoa (efeitos de fundo da câmera) | Apache 2.0 |
| MediaPipe BlazeFace, do Google (conversão ONNX: fernandotonon) | Achar o rosto (Seguir rosto) | Apache 2.0 |
| [Barlow](https://github.com/jpt/barlow), de Jeremy Tribby | Fonte das letras | SIL Open Font License 1.1 |
| [Material Icons](https://github.com/google/material-design-icons), do Google | Ícones | Apache 2.0 |
| [AndroidX](https://developer.android.com/jetpack/androidx), do Google | Bibliotecas do Android | Apache 2.0 |
| [Shizuku](https://github.com/RikkaApps/Shizuku-API), da RikkaApps | Acesso extra opcional (Medidor de FPS sem root) | Apache 2.0 |
| [HiddenApiBypass](https://github.com/LSPosed/AndroidHiddenApiBypass), do LSPosed | Funções do sistema que o Android esconde | Apache 2.0 |

O texto completo das licenças das IAs e da fonte vai dentro do app, na pasta `assets`.

Os efeitos sonoros escolhidos no app vêm do site [MyInstants](https://www.myinstants.com), que o app abre como um navegador. Os sons não vêm junto com o IVO LIVE e pertencem a quem os enviou para o site.

"OBS" e "Stream Deck" são marcas dos seus donos. O IVO LIVE não tem ligação com eles.
